# Chat - Tell 即时通讯

基于 Tell 框架的即时通讯聊天应用实例，支持用户注册登录、好友添加、实时聊天等功能。

## 功能

- 用户注册与登录
- 添加/管理好友
- 一对一实时聊天
- 消息通知
- 管理员后台面板
- PWA 支持（Service Worker 离线缓存）

## 技术栈

- 前端：原生 HTML / CSS / JavaScript
- 后端：Express + Supabase（PostgreSQL 实时数据库）
- 实时通信：Supabase Realtime
- 认证：bcryptjs 密码加密

## 部署

支持 Vercel 一键部署，配置 Supabase 环境变量即可运行。
